# Logistica Lab · Esercitazione 04

Simulatore interattivo per il dimensionamento di un magazzino tradizionale con carrelli trilaterali. Consente di esplorare la pianta del magazzino, variare il numero di corridoi e confrontare i tempi di ciclo e il fabbisogno di carrelli.

Per avviare il simulatore, apri [site/index.html](site/index.html) nel browser. Il sito usa HTML, CSS e JavaScript e non richiede installazione.
